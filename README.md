### NHQM RateLimit

**Lightweight. Secure. Built for Developers.**

NHQM RateLimit is a lightweight Python library designed to control request rates, prevent excessive API usage, and improve application stability.

Built with a precise sliding-window algorithm, it provides per-user and per-IP rate limiting, thread-safe request tracking, automatic request expiration, and retry-time calculations.

With zero external dependencies and a simple integration process, NHQM RateLimit helps developers manage traffic efficiently and protect their applications from excessive requests.

**Key Features:**
- Sliding-window rate limiting
- Per-user and per-IP request tracking
- Thread-safe operations
- Automatic expiration of request records
- Retry-after and remaining-request information
- Zero external dependencies
- Python 3.9+ support

**Simple by Design. Reliable by Nature.**

*Note: The current version operates within a single Python process and is not a complete DDoS protection solution.*
